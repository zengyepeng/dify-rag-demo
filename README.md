# 基于Dify搭建的私有知识库RAG问答助手
> 🎯 个人AI大模型入门实训项目，零代码实现检索增强生成RAG

## ✨ 项目简介
本项目使用Dify平台搭建私有文档问答机器人，属于RAG（检索增强生成）应用。
将自定义TXT文档上传至知识库，系统自动完成文档切片、文本向量化、向量存储；用户提问时，优先检索文档内相关片段，交给大模型参考作答。
严格约束模型：文档无对应信息时禁止编造内容，缓解大模型幻觉问题。

## 🛠️ 技术要点
- RAG核心流程：文档分块(Chunk) → Embedding向量化 → 向量库语义检索 → LLM生成回答
- 平台：Dify（云端版，无需Docker、不需要GPU显卡）
- 支持文件：txt、md、docx、PDF（扫描图片PDF需要开启OCR）
- 检索模式：高质量检索
- 提示词约束：抑制模型幻觉，只依据参考文档回答

## 📌 功能
1. 上传私有学习笔记、手册、资料构建专属知识库
2. 多文档混合检索，跨文档合并答案
3. 无相关资料时直接告知用户，拒绝瞎编
4. 支持一键分享对话链接，他人免登录使用

## 📝 系统提示词
```
你是文档问答助手，请严格根据提供的参考内容回答用户问题。
如果参考内容里面没有答案，直接告诉用户：当前文档没有相关信息，不要编造、不要瞎猜。
回答简洁易懂，适合新手理解。
```

## 🚀 快速复现步骤
1. 访问Dify云端，注册账号
2. 知识库 → 创建【即用型知识库】，上传文档，默认参数切片处理
3. 工作室 → 创建【聊天助手】空白应用
4. 在编排页面添加对应知识库，粘贴提示词
5. 右侧预览窗口调试测试，验证检索效果
6. 发布应用，复制分享链接对外使用

## 💡 适用场景
个人笔记问答、产品手册查询、内部资料检索、学习资料问答
